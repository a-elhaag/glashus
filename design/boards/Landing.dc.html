What it does

Three checks other drives skip.

Before you share

It reads the file before the link exists.

Deterministic detectors find IDs, bank numbers and API keys. You choose a redacted copy or the original, and the link always has an end.

  • Pattern and checksum matching, not AI guesses
  • Expiry, download cap and PIN on every link
  • The original never leaves your drive

After you share

One map of every route out.

Links, people and AI reads drawn on a single graph. The exposed routes are the only colored lines.

  • Exposure score that moves when you fix things
  • Canary files that alert you when opened
  • Alerts when many files change at once
When AI helps

AI reads nothing without a receipt.

Consent is per folder. Sensitive values are masked before anything is sent. Instructions hidden inside files are stripped.

  • A log of every read: file, purpose, what was sent
  • Answers cite the page they came from
  • Pause all AI in one click

Built on Google Cloud

Ten managed services. No servers to patch.

The whole stack is defined in Terraform and shipped by GitHub Actions. This is the path one file takes.

1UploadSigned URL from the browser
2QuarantineCloud Storage bucket
3TriggerEventarc
4ScanCloud Run job
5DetectSensitive Data Protection
6IndexFirestore
7ReadyClean bucket, versioned
Cloud RunAPI and scan workers. Scales to zero.
Cloud StorageQuarantine and clean buckets, versioning, lifecycle rules, signed URLs.
FirestoreMetadata, shares, quotas, graph, vectors, audit and AI logs.
Firebase AuthenticationSign-in and JWT checks on every request.
Vertex AI (Gemini)Chat, naming, version diff, embeddings at 768 dimensions.

EventarcRuns the scan when an object lands in quarantine.
